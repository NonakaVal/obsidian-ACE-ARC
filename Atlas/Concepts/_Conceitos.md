# Conceitos

Esta pasta é o coração do seu **Atlas** — onde suas notas de estudo, conceitos aprendidos e referências teóricas vão morar.

## Como usar

- Crie notas para cada conceito que você aprender
- Conecte conceitos com `[[wikilinks]]`
- Use tags para categorizar por tema (`#conceito`, `#referencia`, etc.)

## Exemplo de notas que cabem aqui

- Um resumo de um artigo que você leu
- Explicação de um framework (como ACE, ARC, PARA)
- Definição de um termo técnico
- Mapa mental de um assunto
